## 状态怎么读

| 标记 | 含义 |
|---|---|
| ✅ 已验收 | 已实现，且有对应专项/线上验证记录；仅在记录覆盖范围内成立 |
| 🟡 部分具备 | 已有代码或部分机制，但完整目标/专项验收未完成 |
| 🔵 外部实测 | ComfyUI真实生成通过，尚未接入LumenX正式业务链 |
| ⚪ 未开始 | 尚无对应运行时实现；文档、模板或已有archiver代码不算迁入完成 |
| ⏸ 后置 | 有需求但本期不承诺，满足前置条件后再安排 |

“本周”表示安排，不表示正在编码；实际开工后才标记“进行中”。不计算混合完成百分比，避免将单次模型实测等同于产品功能交付。
